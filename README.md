# One Letter: Coffee or Tea — "A"

Entry for the make.fun bounty *One Letter: Coffee or Tea*. The whole
entry is a single letter, and this one stands for coffee: **A**.

`main.ts` (Node 22, program/v1) writes exactly one character — `A`,
no newline, no punctuation — to `/output/entry.txt`. Before writing
it checks the letter is one of the two the contest allows, and after
writing it reads the file back and verifies it byte for byte, so the
entry that reaches the judge is exactly the one letter intended.

Why coffee: judged on which choice feels more vivid, funnier or
truer, coffee is the fuller, more alive answer — the bold, electric
drink people build their mornings around — and the honest one.
